# Capsule Companion

Ein persönliches, erweiterbares Capsule- und Packlisten-Dashboard für GitHub Pages.

## Funktionen

- Capsule-Übersicht mit Filtern für helle, dunkle und Layer-Teile
- Abhakbare Packliste inklusive Basics, Beauty, Technik und Unterwegs
- Eigene Einträge pro Kategorie
- Lokale Speicherung im Browser
- Outfit-Inspiration für mildes, kühles, regnerisches sowie kaltes Wetter
- Responsive Darstellung für Smartphone und Desktop

## Lokal öffnen

Die Seite benötigt keinen Build-Prozess. `index.html` kann direkt im Browser geöffnet oder über einen einfachen lokalen Webserver bereitgestellt werden.
